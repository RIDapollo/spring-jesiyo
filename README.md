# spring-jesiyo

👤 My Contribution (회원 관리 및 보안)
본 프로젝트에서 저는 회원 인증/인가와 보안 체계 구축, 그리고 포인트 결제 로직을 담당했습니다.

🔐 보안 중심의 인증 및 인가 시스템 구축
   Spring Security 적용: 사용자 권한 등급에 따라 접근 제어(URL 인터셉트)를 설정하여 비인가 사용자의 접근을 차단하고 보안을 강화했습니다.
   CSRF 방어: CSRF 토큰 검증을 구현하여 외부 위조 요청으로부터 시스템을 안전하게 보호했습니다.
   비밀번호 보안 강화: BCrypt 암호화 알고리즘(salt 및 반복 연산 포함)을 적용하여 레인보우 테이블 공격을 방어하고, 개인정보 보호를 위한 마스킹 로직을 적용했습니다.

💰 경매 연동 포인트 정산 시스템 설계
   포인트 금융 로직: 포인트 충전, 잔액 관리, 출금 요청 및 낙찰 정산 로직을 설계하여 경매 서비스의 금전 거래 데이터 무결성을 보장했습니다.
   사용자 편의성 고려: 카테고리 기반 관심 상품(찜) 기능을 통해 사용자 경험을 개선했습니다.

🛠️ 향후 개선 계획
   사용성 개선: 가입 장벽 완화를 위한 OAuth 2.0 소셜 로그인 도입 및 성인 인증 서비스(PASS 등) 연동을 고려하였습니다.
   보안 고도화: 금전 거래의 안전성을 높이기 위해 2차 인증(2FA) 도입을 계획하였습니다.
